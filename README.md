# GibitecaSQL
Banco de dados simulando uma gibiteca (biblioteca de quadrinhos).
Projeto feito para a matéria de Arquitetura de Banco de Dados.

## Ferramentas utilizadas:
- Python.
- SQLAlchemy.
- Extensão PyMySQL.

## Instruções para execução:
O projeto deve ser rodado no Xampp, com servidor Apache e MySQL, com configuração pelo phpMyAdmin.
É necessário criar um banco de nome "gibis" pelo phpMyAdmin, utilizando o código do arquivo .sql para a criação do banco. 
A manipulação do banco é feito pelo arquivo main.py, via terminal.

## Informações sobre o banco:
Entidades:
- Editoras.
- Autores.
- Categorias.
- Gibis.
